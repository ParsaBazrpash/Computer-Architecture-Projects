# Computer-Architecture-Projects
Computer Architecture Course Projects

Our program is in MIPS MARS and is inspired by the Math-Match minigame. It is an interactive memory game that helps the users with their mathematical education. It tests them on their times table from 2x2 to 5x5. The game has a total of 16 cards (in a 4x4 grid) and a total of 8 pairs. In other words, the grid has 8 equations and 8 of the corresponding answers.

To win the game, you need to match all the pairs. The start off with a “?” which represents that that is not revealed or matched. Each turn, the user can reveal 2 cards. When flipping cards, there is a sound cue. If the cards match (ex. 2x3=6), then they stay revealed, but otherwise, they flip back over. If the user inputs a card that is already matched or revealed then the flipping sound effect is no longer heard. If the user inputs a “0”, then they quit the game. Users get to see how much time elapsed after every input, and in the end get their final time when they win the game!
